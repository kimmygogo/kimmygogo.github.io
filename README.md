# ACMG 双模式评分器

一款支持 **严格 ACMG 模式** 和 **教学简化模式** 的基因变异评分工具，适用于临床遗传咨询与教学培训。

## 🚀 如何使用？

1. 打开网页：[https://your-username.github.io/acmg-scorer](https://your-username.github.io/acmg-scorer)
2. 选择左侧「严格模式」或「教学模式」
3. 填写证据项（PVS1, PM2, PP1...）
4. 点击「计算」即可看到最终分类

## 📚 支持规则

- 严格模式：遵循 ACMG 2015 Table 5 的证据组合规则
- 教学模式：基于净分值阈值（≥10 致病，≤−10 良性）

> ⚠️ 教学模式仅用于教学演示，不可用于正式临床报告！
